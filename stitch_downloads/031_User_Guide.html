Introduction to AgentShield AI

AgentShield AI is an autonomous, high-density monitoring and response platform designed for modern SecOps environments. It utilizes distributed intelligent agents to establish a secure perimeter, detecting anomalies and executing rule-based mitigations in real-time. This guide will walk you through deploying your first agent and understanding the core telemetry.

Quick Start

1

Initialize Environment

Install the core CLI tools required for deploying AgentShield nodes in your cluster.

$ npm install -g @agentshield/cli
2

Authenticate Cluster

Bind your local environment to the Mission Control dashboard using your API token.

$ shield auth login --token=YOUR_API_TOKEN
